## Sub-Goal
M8. Agent Teams와 CI/CD — 개인에서 조직 자동화로

* Title: Agent Teams와 CI/CD — 개인에서 조직 자동화로
* Synopsis: 개인 수준의 AI 활용을 CI/CD 파이프라인에 통합하여 조직 수준으로 확장한다. 수강 후 Agent Teams를 설계하고 CI/CD에서 자동 실행할 수 있다.

* Build: Agent Teams + CI/CD로 자동 코드 리뷰 파이프라인 구축
    * 결과물: Agent Teams 설정 + GitHub Actions 워크플로우 + Plugin
    * 예시: Agent Teams 설정 → claude -p 비대화형 실행 → GitHub Actions PR 리뷰 자동화 → Plugin으로 팀 배포
* Core Content:
    * Agent Teams: Team Lead 패턴, Writer/Reviewer, Fan-out
    * CI/CD: claude -p 비대화형 모드, --allowedTools, GitHub Actions
    * Plugins: 팀 배포를 위한 번들링
